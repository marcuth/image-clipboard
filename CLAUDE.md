## What this is

ImageClipboard is a Tauri v2 desktop app (React 19 + TypeScript + Vite 7 + Tailwind CSS 4) for pasting, annotating, enhancing and sharing images. The Rust side owns every outbound network request, so the webview never hits CORS.

## Commands

```bash
npm run dev            # Vite dev server on :1420
npm run tauri dev      # full desktop app
npm run format         # Prettier
npm run lint           # ESLint (must have 0 errors)
npm run build          # tsc + Vite build
cd src-tauri && cargo test
```

## Architecture

### Frontend (`src/`)

- `App.tsx` switches between `WelcomeScreen` and the editor, owns the theme and the global paste listener.
- `hooks/use-canvas-editor.ts` is the editor state machine: canvas refs, undo/redo history, zoom/pan, crop, text, mouse and keyboard handling. Pixel changes must go through its history (`pushHistory`, `replaceWithImage`) or undo breaks.
- `services/canvas-draw.ts` has the pure drawing functions (line, arrow, shapes, blur, focus).
- `services/image-service.ts` covers clipboard, file download and the Tauri `invoke` calls for Catbox and ImgBB.
- `services/ai-service.ts` runs local background removal (`@imgly/background-removal`, WASM) and calls the Rust Bigjpg command.
- `components/editor/` holds the header, stage, footer, crop overlay, and the `save-dialog` and `ai-dialog` dialogs. `components/ui/` is generated by the shadcn CLI: do not edit it by hand.

### Backend (`src-tauri/src/`)

- `lib.rs` registers the Tauri commands `upload_to_catbox`, `upload_to_imgbb` and `bigjpg_enlarge`. They are `async` and run the blocking `ureq` work through `spawn_blocking`.
- `http.rs` has the shared `ureq` agent (browser User-Agent, HTTP errors returned as values), base64 and URL encoding, and the multipart builder.
- `uploaders/{catbox,imgbb,bigjpg}.rs` hold one service each. `bigjpg.rs` is a Rust port of the sibling `bigjpg-open` TypeScript client.

## Conventions specific to this repo

- No code comments. Make names, constants and small functions carry the meaning (for example `SNAP_ANGLE_STEP`, `ALLOWED_SCALES`).
- New backend logic needs unit tests. Keep parsing and request-building in pure functions so they can be tested without network access; the goal is 100% coverage.
- Bigjpg without an account only allows 2x enlargement, and `ALLOWED_SCALES` in `bigjpg.rs` enforces that.
- The ImgBB API key lives only in the webview's `localStorage` and is sent per request to the Rust command.
- Documentation screenshots live in `docs/screenshots/` and are referenced from `README.md`.

## Gotchas

- Shell heredocs containing quotes break in the Bash tool on Windows. Write files with the Write tool and run scripts from a file.
- A dev server may already be listening on port 1420. Check before starting another one.
- `cargo test` needs a long first compile (several minutes).
